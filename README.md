# mozinazori# ことばなぞり

GitHub Pages 用の静的サイトです。

## ファイル構成
- `index.html` : アプリ本体
- `problems.js` : 問題データ。今後の問題追加は基本的にここだけ編集します。
- `images/` : 問題画像
- `.nojekyll` : GitHub Pages 用

## GitHub Pages
このフォルダの中身をリポジトリの公開対象フォルダへそのまま置けば動きます。
`index.html` を入口にしてください。

## 問題
100問登録済みです。
毎回ランダムに10問を選び、出題順もランダムです。

問題を増やす場合は `problems.js` の `window.PROBLEMS` に、

```js
{ id:"sample", image:"images/sample.png", hira:"さかな", kata:"サカナ" },
```

の形式で追加します。

## 画像
現時点で画像そのものは同梱していません。
必要なファイル名は `images/README.txt` に一覧があります。
画像が無い問題でもアプリは停止せず、仮画像で動作します。

## かなデータ
かなの字形データは HTTPS の CDN から取得します。
GitHub Pages 上では通常のWebページとして配信されるため、HTML直開き時に起きた `file://` 制限は発生しません。

## ゲーム
- ひらがな / カタカナ
- 時間制限なし / あり
- 10問でクリア
- 正解：星エフェクト + 「つぎへ」
- 時間切れ：画面全体の爆発後、自動で次問題
- クリア：同じ設定で「もういちど」


## ハードモード
タイトル画面で「ノーマル / ハード」を選択できます。

- ノーマル：線から外れると車が止まり、車の近くへ戻ると再開します。
- ハード：ノーマルで車が止まる条件になった時点でその場で爆発し、現在の1画だけ最初からやり直します。
- 完成済みの前の画・前の文字は残ります。

## 時間制限
時間制限ありでは、1文字あたり15秒です。
例：4文字＝60秒、6文字＝90秒。


### ハード判定調整
ハードモードでは、ノーマルで車が止まる条件になった時点で即爆発するように変更しました。
